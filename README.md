# Jcars – Vehicle Sales Data Analysis

## 1. Project Overview

Jcars is a data analytics project focused on cleaning, transforming and analysing vehicle sales data using PostgreSQL 
and Power BI.

The project applies SQL techniques to improve data quality, generate meaningful business insights and support data-driven 
decision-making.

## 2. Project Objectives

- Clean and standardise raw vehicle sales data.
- Identify and handle duplicate and missing records.
- Transform inconsistent financial and date fields.
- Analyse sales, revenue and operational performance.
- Create reusable SQL views for reporting.
- Prepare cleaned data for Power BI visualisation.

## 3. Tools and Technologies

- PostgreSQL – Database management and SQL analysis.
- pgAdmin – SQL development and database administration.
- Aiven – Hosted PostgreSQL database.
- Power BI – Data visualisation and reporting.

## 4. Dataset Description

The dataset contains vehicle sales transaction records, including:

- Order ID and transaction dates.
- Customer information and geographical locations.
- Vehicle make, model and category.
- Units sold and selling prices.
- Unit costs, discounts and logistics costs.
- Payment and delivery status.
- Customer ratings and reviews.

## 5. Data Cleaning and Transformation

SQL was used to perform the following operations:

- Identifying and removing duplicate records.
- Handling NULL values and inconsistent entries.
- Standardising currency and numerical fields.
- Cleaning percentage and discount values.
- Correcting date formats and inconsistencies.
- Standardising categorical values.
- Validating financial and operational data.

## 6. SQL Analysis

Several analytical views and queries were developed to examine:

| Analysis | Purpose |
|---|---|
| Revenue and logistics | Examine sales revenue and logistics costs |
| Cancellation analysis | Investigate cancelled transactions |
| Car performance | Evaluate vehicle sales performance |
| Monthly growth | Analyse changes in monthly sales |
| Sales representative performance | Compare sales performance across representatives |
| Delivery analysis | Examine delivery duration and efficiency |
| Payment analysis | Identify incomplete and pending payments |

## 7. Power BI Integration

Cleaned data and SQL views provide the foundation for Power BI reporting.

The reporting process supports:
- Sales performance monitoring.
- Revenue and financial analysis.
- Vehicle and regional comparisons.
- Monthly performance trends.
- Interactive filtering and dashboard exploration.

## 8. Skills Demonstrated

- PostgreSQL and SQL querying.
- Data cleaning and transformation.
- Database management.
- Data validation and quality assurance.
- Statistical and exploratory analysis.
- SQL views and aggregations.
- Performance analysis and reporting.
- Power BI data visualisation.

## 9. Project Workflow

Raw Data → PostgreSQL → SQL Cleaning → Data Transformation → Analytical Views → Power BI Reporting

## 10. Conclusion

This project demonstrates the application of SQL and business intelligence tools in transforming raw vehicle sales 
data into structured, analysis-ready information. It strengthens practical capabilities in data management, analytical 
problem-solving and performance reporting.
